# Универсальный ИИ-ассистент для малого бизнеса

Отдельный проект. Пока умеет главное из MVP: **принимать заказы в Telegram и
записывать их в базу**. Построен универсально — любой бизнес это отдельный
«тенант» (строка в таблице `businesses`), данные бизнесов не смешиваются.

## Что уже есть
- База данных с таблицами `businesses`, `clients`, `orders` (все привязаны к `business_id`).
- Telegram-бот, который ведёт клиента по шагам и оформляет заказ.
- Первый бизнес для теста — «Флоренция».

## Как запустить (по шагам)

1. **Установить Python** (если ещё нет): https://www.python.org/downloads/
   При установке поставь галочку «Add Python to PATH».

2. **Установить библиотеки.** Открой терминал в этой папке и выполни:
   ```
   pip install -r requirements.txt
   ```

3. **Получить токен бота.** В Telegram напиши боту **@BotFather**, команда
   `/newbot`, придумай имя. Он выдаст токен (длинная строка).

4. **Вписать токен.** Скопируй файл `.env.example`, назови копию `.env`,
   и вставь туда свой токен.

5. **Создать базу** (один раз):
   ```
   python setup_db.py
   ```

6. **Запустить бота:**
   ```
   python bot.py
   ```
   Открой своего бота в Telegram, напиши `/start` — и попробуй оформить заказ.

## Сайт и панель заказов (веб)

Есть красивый сайт в стиле «Джарвиса/космоса» и панель заказов для владельца.

Запуск веб-сервера:
```
python server.py
```
Потом открой в браузере:
- Сайт (лендинг): **http://127.0.0.1:8000**
- Панель заказов: **http://127.0.0.1:8000/dashboard.html**

Панель показывает заказы из базы вживую и обновляется сама каждые 15 секунд.

## Файлы проекта
| Файл | Что делает |
|------|-----------|
| `schema.sql`   | структура таблиц базы |
| `database.py`  | функции чтения/записи (все через `business_id`) |
| `config.py`    | настройки и секреты |
| `setup_db.py`  | создаёт базу и первый бизнес (запустить 1 раз) |
| `bot.py`       | сам Telegram-бот |
| `server.py`    | веб-сервер: отдаёт сайт + API-розетка для заказов |
| `web/index.html` | сайт-лендинг (космический стиль) |
| `web/dashboard.html` | панель заказов для владельца |
| `web/style.css`, `web/stars.js` | стили и анимация звёзд |

## API-розетка (для подключения приложения заказов)
- `GET  /api/orders` — получить список заказов.
- `POST /api/orders` — добавить заказ. Тело JSON: `{"text": "...", "phone": "...", "date_wanted": "..."}`.
