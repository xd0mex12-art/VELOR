# Партнёрская программа VELOR — план работ

> **Для исполнителя:** задачи идут по порядку, каждая заканчивается зелёными
> тестами и коммитом. Спецификация:
> `docs/superpowers/specs/2026-09-30-partnerskaya-programma-design.md`.

**Цель:** партнёр приводит клиента по ссылке и получает 15% с каждой его
оплаты, пока клиент платит.

**Устройство:** две новые таблицы (`partners`, `partner_earnings`) и два поля
у бизнеса. Вся логика в одном модуле `partners.py`. Комиссия начисляется в
единственной точке — при активации и продлении подписки, через которую
проходит и ручная отметка оплаты, и будущий платёж из ЮKassa.

**Технологии:** Python 3.12, FastAPI, прямой SQL (без ORM), собственный
тестовый раннер `tests/run_all.py`.

## Общие ограничения

- **Ноль выдуманных возможностей.** Не объявлять того, чего нет в коде.
- **Мультитенантность — красная линия.** Партнёрские данные не должны давать
  доступа ни к одной строке чужого бизнеса.
- **ЮKassa не включаем.** Ключи не задаём, `billing.configured()` остаётся
  ложью. Код только готовится к тому, что оплата появится позже.
- **Схема меняется только так, как описано в спецификации** — две таблицы и
  два поля, больше ничего.
- **Секреты в переписку не попадают.** `.env` остаётся в `.gitignore`.
- Тексты в интерфейсе и комментарии — по-русски, как во всём проекте.
- Тесты пишутся в стиле `tests/t_*.py`: без pytest, счётчик `ok/fail`,
  запуск через `python tests/run_all.py`.

**Интерфейс:**

```
partners.accrue(bid, plan, months=1, amount=None) -> dict | None
partners.earnings(partner_id=None, unpaid_only=False) -> list[dict]
partners.totals(partner_id) -> dict   # accrued, paid_out, due, clients, paying

```

Сумма: если `amount` передан — берётся он; иначе цена тарифа из `plans.py`,
умноженная на месяцы. Комиссия — `amount * share_pct / 100`, округление до
целого рубля. Если у бизнеса нет партнёра — `None`, ничего не пишется.

не начисляется; оплата за 3 месяца даёт одну строку на тройную сумму;
изменение доли партнёра не меняет уже записанные строки; `mark_paid`
закрывает долг и `due` уменьшается; бизнес без партнёра не создаёт строк.

- [ ] **Шаг 2.** Прогнать — падает.

- [ ] **Шаг 3.** Реализовать. Вызов из `trial.py` обернуть в `try/except`:
